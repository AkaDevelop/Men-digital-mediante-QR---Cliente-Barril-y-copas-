# Barril y Copas — Menú Digital

Menú digital para Barril y Copas, accesible mediante código QR.

## Estado

En desarrollo.

## Objetivo inicial

Crear un menú digital con lectura mediante QR cuyos productos puedan ser administrados
mediante una plantilla de Google Sheets.

## Integraciones previstas

- Google Sheets — datos del menú
- Google Drive — almacenamiento de recursos

## Repositorio

Proyecto gestionado mediante Git y GitHub.
